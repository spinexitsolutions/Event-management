# API reference

Base URL: `/api/v1`. Responses are `{ "data": …, "meta"?: … }`; errors are `{ "error": { "code", "message", "details"? } }`.
Mutating requests require the `X-CSRF-Token` header (value of the `me_csrf` cookie, or `GET /auth/csrf`). Authentication uses the httpOnly `me_session` cookie.
Request bodies are validated with zod — see the schema next to each route in `server/src/modules/`.

_Generated by `node scripts/gen-api-docs.mjs`._
