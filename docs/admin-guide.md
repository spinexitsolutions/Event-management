# Admin guide (for the studio team)

Sign in at `/login`. What you see in the sidebar depends on your role (Admin → Staff & roles).

## Change the website — no code, no redeploy
Everything below works as **draft → preview → publish**. Drafts autosave; visitors see changes only after you press **Publish**,
and every publish creates a version you can restore later.

| I want to… | Go to |
| --- | --- |
| Change colours, fonts, sizes, buttons, cards, spacing, header/footer style, motion, or apply a preset | Website → Theme & branding |
| Change logo, favicon, site name, tagline, contact details, address, WhatsApp, social links | Website → Global content → Branding / Company |
| Edit the menu or footer links, the announcement bar, newsletter text, inquiry form options, SEO defaults | Website → Global content |
| Edit the homepage: add / remove / duplicate / reorder sections, change text, photos, videos, buttons, layouts | Website → Pages & homepage → Home |
| Create a new page (e.g. “Winter weddings”) | Website → Pages & homepage → New page |
| Add or edit services, event categories, packages & prices, portfolio projects, testimonials, team, FAQs, client logos, journal posts | Website → Content library |
| Upload, replace or organise photos and videos | Website → Media library |

Tips
- **Photos:** upload high-resolution JPG/PNG/WebP (they are optimised automatically). Always fill in **alt text** — it describes the image
  for visually impaired visitors and search engines. Replacing a file in the Media library updates it everywhere it is used.
- **Prices:** packages can show “Starting from”, a fixed price, or “Price on request”. Only publish prices you stand behind.
- **Consent:** portfolio projects, testimonials and client logos can only be published after you tick the box confirming the client
  authorised it.
- **Live statistics:** statistics sections can count completed events and clients directly from your bookings — or show manual
  numbers you have verified.

## Sales pipeline
1. **Inquiries** arrive from the website (reference `INQ-XXXXXX`, confirmation email to the client, alert to the team).
   Assign a planner, log calls/notes, schedule a consultation, set reminders. Statuses: New → Contacted → Consultation scheduled →
   Requirements received → Quotation sent → Negotiation → Won / Lost.
2. **Quotations:** create from the inquiry, add services/packages/custom lines, optional extras, taxes, discounts and the payment
   schedule. Totals are always recalculated by the system. **Send** emails the client a link to their portal (inviting them if needed).
   Editing a sent quotation creates a new version — the history is kept.
3. The client reviews in the **client portal**, picks optional extras, and accepts, declines or requests changes.
4. **Convert to booking** once accepted: the event, services and instalment schedule are created automatically.

## Running the event
- **Booking workspace:** record the signed agreement → the advance payment confirms the booking automatically → plan with tasks
  (apply a template), vendors, inventory, guests (RSVP, QR invitations, check-in), documents and messages with the client.
- **Calendar:** events, consultations, payment due dates, vendor deliveries and deadlines in one view.
- **Finance:** instalments, online and manual payments, invoices (PDF), refunds (requested by one person, approved by another), expenses
  and vendor payments. Reports separate *quotation value* (estimates), *confirmed contract value*, *payments received* and *outstanding*.
- **Completing:** after the final payment the booking completes and the client receives a thank-you and feedback request.

## Emails & automations
Edit email wording and switch automations on/off in Administration → Emails & automations. The **Outbox** shows every message and
whether it was sent, failed (with retry) or skipped because no email provider is configured.
